# code 目录说明

## 概述

本文件夹为大学软件工程专业所有代码专属存放目录，仅存放源代码、程序文件、项目源码、刷题代码，**不存放**软件安装包、环境工具、安装配置文件（此类文件统一存放至 `develop` 文件夹）。

所有目录命名统一采用 **小写下划线规范**，跨系统兼容。

---

## 目录结构

```
code/
├── README.md              本说明文档
├── course/                课程随堂作业代码
├── personal_demos/        个人练习 Demo
├── projects/              课程设计 & 正式项目
└── algorithm/             算法刷题代码
```

---

## 目录结构及详细用途

### 1. `code/course/` 课程随堂作业代码

存放大学各门专业课的日常作业、课堂练习、课后实操代码，按课程分类建子文件夹管理，为日常课业基础代码归档目录。

- **包含但不限于**：C语言、Java、Python、数据结构、数据库、操作系统、软件工程等课程的课后练习、课堂小案例、随堂实操代码。
- **存放规则**：单文件、小型练习代码，无完整项目架构，仅为课程基础练习。
- **二级结构**：一门课一个文件夹（英文小写下划线，如 `java/`、`data_structure/`），需要时再按 `ch01_` / `lab01_` 章节或实验编号拆分子目录；Java 源文件名因编译器要求可用驼峰，与类名保持一致。
- **详细使用规则见 [`course/README.md`](course/README.md)**。

### 2. `code/personal_demos/` 个人练习 Demo

存放自主学习、课余练习、自学技术的小型测试案例、功能 Demo 代码。不属于课堂作业、不属于正式课设项目，纯个人练手、技术试水代码。

- **例如**：新语法测试、功能小尝试、第三方库使用测试、自学框架小案例等。
- **二级结构**：一个 Demo 一个文件夹，命名 `技术栈_主题_类型`（如 `vue2_admin_demo/`），扁平存放，数量多时按技术栈分层；Demo 不需 `src/res/report` 三件套，但建议写三五行 `README.md` 记录学什么与状态（`doing` / `done` / `abandoned`）。
- 试水成功、决定做完整的 Demo 应**移动到 `projects/`** 并按项目规范归档。
- **详细使用规则见 [`personal_demos/README.md`](personal_demos/README.md)**。

### 3. `code/projects/` 课程设计 & 正式项目

存放所有课程设计、期末大作业、团队项目、竞赛小项目等具备完整架构的正式项目代码，是核心项目归档目录，为提前规划好的核心项目目录，可直接创建使用，专门用于归档完整正式项目。

- 每个项目单独新建独立文件夹（命名格式：`course_design_项目名称`）
- 单个项目内部统一结构：

| 目录 | 用途 |
|---|---|
| `src/` | 项目全部源代码 |
| `res/` | 项目资源文件、SQL 脚本、配置文件、静态素材 |
| `report/` | 对应课设报告、项目文档、答辩资料 |

- **核心用途**：用于期末提交、作业归档、简历与作品展示。
- 项目在 `projects/` 下**扁平排列**，不再按学期/课程分层；报告文件用英文序号命名（`01_proposal.docx`）。
- **详细使用规则见 [`projects/README.md`](projects/README.md)**。

### 4. `code/algorithm/` 算法刷题代码

存放数据结构与算法练习、LeetCode、牛客、PTA 等刷题代码，以及算法实验、算法作业源码。

- 按题型、平台或学期分类管理，用于积累算法基础、备战考试和竞赛。
- 二级结构：`leetcode/`、`nowcoder/`、`pta/`、`course_exp/`（算法实验与算法作业）、`template/`（算法模板）；平台目录下按「一题一目录」存放，命名 `题号_英文短名`。
- **详细使用规则见 [`algorithm/README.md`](algorithm/README.md)**。

---

## 统一存放规范（强制遵守）

- 仅存放 `.c` / `.java` / `.py` / `.sql` / `.html` / `.css` / `.js` 等源码文件及项目配置文件
- **禁止存放**：软件安装包、压缩包、SDK、运行环境、安装教程、大型资源文件
- 所有文件夹、文件统一使用 **小写 + 下划线** 命名，无中文、无空格、无特殊符号
- **归档名 vs 提交名**：归档一律英文小写下划线；若课程/老师要求提交中文名称的文件（如「课设报告-张三.docx」），采取「**归档用英文名，提交时另存一份中文名副本**」——归档目录只保留英文名母版，中文名副本放到提交用的位置，不进归档目录
- 零散练习、日常代码归入 `course` 或 `personal_demos`；完整课设、正式项目归入 `projects`；算法刷题代码统一归入 `algorithm`
- 所有课设项目做到 **代码 + 报告 + 资源** 统一归档，不拆分存放
