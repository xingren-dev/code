## 每个子文件夹里放什么

- `.sql` 脚本，文件名用英文小写下划线，例如 `practice_01_basic_select.sql`
- 脚本**必须能直接跑通**：开头写 `USE 库名;`，中间是练习语句，尽量用注释标出每句要干什么
- 讲义在 `D:\学习资料\MySQL入门+晋级+存储过程+面试题全套视频教程精讲\MySQL初级\document-md文件请安装typora工具打开\`，共 11 章 md，用 Typora 打开（你 `D:\Typora` 已装）
- 课件自带的 `resources\powernode.sql` 是配套演示库，练查询直接导入它
